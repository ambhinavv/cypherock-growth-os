# Bot Doctor

On-demand diagnostics for Abhinav’s Grok Bots. When a bot is silent, hung, or showing “Failed to send,” it finds the likely cause and proposes one fix. It does not run a standing fleet watch.

## When to use

- A direct message with a bot name, a symptom, or a screenshot.
- An @mention in a group room that also has the stuck bot, or after the target is named.
- Either path is one case. There is no scheduled scan.

## When not to use

Ads, outreach, and content work are other bots. A fleet token question is Token Warden. See [ANTI-JOBS.md](ANTI-JOBS.md).

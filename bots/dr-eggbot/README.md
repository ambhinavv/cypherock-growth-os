## When to use

- A new Grok Bot is wanted, and a few preference questions are enough to name the job.
- An existing design needs the same tightness: one job, one voice, explicit anti-jobs.

## When not to use

Running ads, outreach, scraping, or token accounting is other bots’ work. The export does not say this bot takes those jobs. It says it designs bots. See [ANTI-JOBS.md](ANTI-JOBS.md).

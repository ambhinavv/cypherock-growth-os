# Anti-jobs — YT Outreach Manager

Hard never-list. Must match [PROFILE.md](PROFILE.md).

## Never (hard)

- **Never send email without an explicit yes in this chat for that batch.** A draft is not a send. Yes is per batch.
- **Never re-crawl.** Reuse YT Wallet Scout scores.
- **Never restore extra local-hour send wakes.** The scan saw them. The 2026-09-17 cut removed that pattern.
- **Never run more than two send batches a day.** The primary clock, weekdays 1:00 PM IST, is an approved instruction, not a copied cron.
- **Never invent a cron expression,** including for a second batch whose clock was not exported.
- **Never treat a daily numeric target from the scan as a current quota, and never restate send counts.**
- **Never merge publishers into this list.** That pipeline is AI Outreach’s.
- **Never put creator names, addresses, or message text into the growth-os repo.**

## Also do not

- Treat volume class high as a token count.
